## 📌 نظرة عامة على المشروع (Project Overview)

**منصة توصيله (Tawseela Platform)** هي منظومة رقمية متكاملة للنقل الذكي والخطوط التشاركية صُممت خصيصاً لتغطية واحتياجات **محافظة النجف الأشرف** في العراق. تجمع المنصة بين:

1. **الخطوط التشاركية المنتظمة (Ride Pooling & Commute):** تمكين الركاب (موظفين، طلاب جامعات الكوفة والفرات الأوسط، عوائل) من حجز مقاعد مع كباتن يسلكون نفس المسار يومياً، مع تقاسم الأجرة وحساب أفضل خط سير يمر بالركاب تباعاً.
2. **الرحلات الفورية وطلب السيارات (On-Demand Taxi):** توفير سيارات الأجرة القريبة بنظام المطابقة الجغرافية اللحظية.
3. **لوحة تحكم الأسطول وغرفة العمليات (Fleet Operations Center):** للمشرفين لمتابعة الأسطول، توثيق الكباتن وفحص المستندات الأربعة (البطاقة الوطنية وجهين، وإجازة السوق وجهين)، رسم المسارات وتعميمها، وإدارة شكاوى المستخدمين.

### 📍 النطاق الجغرافي المعتمد (Geographic Coverage - Najaf Province):
- **المركز:** `31.9961, 44.3168` (المدينة القديمة، الحنانة، حي السعد، الغري).
- **الكوفة:** `32.0300, 44.3700` (جامعة الكوفة، مسجد الكوفة، السهلة).
- **المحاور والمناطق الأخرى:** المشخاب، المناذرة، الحيدرية، شارع المطار وشارع الروان.
- يتم تقييد عمليات البحث الجغرافي ضمن حدود النجف الأشرف (`bbox: 44.05, 31.75, 44.65, 32.35`).

## 🧩 المكونات الرئيسية للنظام (Core Components)

### أ. تطبيق الويب الموحد وتطبيق Flutter
- **الموقع الإلكتروني وبوابة الدخول السريعة (`/` و `/captain-login`):**
  - مبنية بتقنيات الويب الحديثة الخفيفة لتوفير أداء فوري (< 500ms) على شبكات الهواتف المحمولة في العراق دون الحاجة لتحميل حزم ضخمة.
  - تدعم تبويبين رئيسيين: تبويب الراكب (تسجيل فوري، اختيار المسار على الخريطة)، وتبويب الكابتن (دخول مباشر برقم الهاتف وكلمة المرور).
- **تطبيق Flutter (`apps/taxi_wisam_flutter`):**
  - تطبيق متعدد المنصات (Android, iOS, Web).
  - متاح عبر الويب على الرابط: `https://www.tawseelaiq.app/app/`.
  - يعتمد نمط Riverpod لإدارة الحالة، ومكتبة `dio` للتواصل مع الخادم، و `flutter_map` و `mapbox_gl` للخرائط والتوجيه.

### ب. خادم المنصة الموحد (Unified Node.js Engine)
- **الملف الرئيسي:** `src/backend/server.js`
- يعمل عبر منفذ `5050` ويدار بواسطة `pm2` تحت اسم `taxi-wisam-api`.
- يوفر معمارية نمطية (Modular Architecture):
  - `modules/auth/authController.js`: إدارة الحسابات، التحقق، وتوليد صفحات الدخول.
  - `modules/admin/adminController.js`: عمليات الإدارة، مراجعة الوثائق، وتعديل الكباتن والركاب.
  - `modules/backup/backupService.js`: النسخ الاحتياطي التلقائي ومراقبة الحالة.
  - `db/index.js`: طبقة تجريد الاتصال بقاعدة بيانات PostgreSQL ومزامنة الذاكرة.

### ج. لوحة التحكم والعمليات الإدارية (Admin Dashboard)
- **المسار:** `src/TaxiWisam.Api/wwwroot/dashboard/` (يخدم على `https://www.tawseelaiq.app/dashboard/`).
- **المكونات:** `index.html`، `app.js`، `style.css`.
- **المصادقة:** اسم المستخدم الافتراضي: `admin` | كلمة المرور: `1122` أو `١١٢٢`.
- **الميزات البارزة:**
  - معاينة فورية لـ 4 وثائق رسمية لكل كابتن مع ميزة التكبير (Image Zoom) والتدوير والتنزيل والاعتماد/الرفض مع كتابة سبب الرفض.
  - خريطة تفاعلية للأسطول عبر Mapbox GL JS مع رسم مسار الكابتن على الشوارع مباشرة وحفظه بالـ Database.
  - أداة توليد كلمات سر عشوائية غير مكررة للكباتن والركاب.
  - فحص فوري لتكرار أرقام الهواتف بين الكباتن والركاب لمنع تكرار الحسابات.
  - نافذة بحث جغرافية في محافظة النجف الأشرف تبدأ بالبحث من أول حرف يتم كتابته.

### د. قاعدة البيانات ونظام الحفظ الدائم (PostgreSQL & Storage)
- **قاعدة البيانات:** PostgreSQL 16 مع إضافة PostGIS لعمليات الهندسة المكانية (`ST_DWithin`, `ST_Distance`).
- **النسخ الاحتياطي اللحظي:** `data/state.json` يوفر طبقة حفظ احتياطي سريعة تضمن عدم فقدان أي بيانات حتى في حال انقطاع اتصال قاعدة البيانات.
- **ملفات المستندات:** تحفظ في `data/uploads/` وتخدم عبر توجيه `/uploads/`.

## 🔄 رحلة المستخدم وسير العمليات (User Flows & Lifecycles)

### 1. رحلة الراكب (Passenger Flow)
1. **التسجيل / الدخول:**
   - يدخل الراكب عبر الموقع أو التطبيق، يكتب اسمه الكامل ورقم هاتفه (0770xxxxxxx أو 0780xxxxxxx) وكلمة المرور.
   - إذا كان الرقم مسجلاً مسبقاً، ينبهه النظام فورا بوجود الحساب.
2. **تحديد خط السير:**
   - يحدد موقع الصعود وموقع الوصول إما بالنقر على خريطة Mapbox أو بالبحث عن أسماء أحياء النجف (مثل: حي الروان، جامعة الكوفة، حي السعد).
   - يتم رسم مسار الراكب باللون الأسود ويتبع الشوارع أوتوماتيكياً عبر Mapbox Directions API.
3. **المطابقة والاشتراك:**
   - يعرض النظام الكباتن الذين تتطابق مساراتهم مع مساره:
     - القريبين جداً (أقل من 500 متر) بخط **أخضر**.
     - المتوسطين بخط **أحمر**.
     - البعيدين بخط **بنفسجي**.
   - يرى الراكب اسم الكابتن ومعلومات سيارته ومساره على الخريطة مباشرة.
   - عند الحجز مع الكابتن، يرى تحركات الكابتن وكم الوقت المقدر المتبقي لوصوله.

### 2. رحلة الكابتن (Captain/Driver Flow)
1. **تسجيل الدخول المخصص:**
   - عبر الرابط المباشر `https://www.tawseelaiq.app/captain-login` برقم الهاتف وكلمة المرور.
2. **إدارة المسار اليومي:**
   - يحدد الكابتن مسار خطه الصباحي والمسائي، ونقاط التوقف، وسعة المقاعد المتاحة في سيارته.
3. **تكامل الملاحة مع تطبيق Waze:**
   - توجد أيقونة خاصة تنقل الكابتن بنقرة واحدة إلى تطبيق **Waze** لاتباع نفس خط السير المحدد على الخريطة والذهاب لنقاط صعود الركاب المشتركين معه دون أي عناء.

### 3. إدارة العمليات المركزية (Admin Operations)
1. **توثيق الكباتن:** مراجعة فورية للمستندات والبطاقات الشخصية ورخص القيادة بدقة عالية واعتماد الحساب ليصبح جاهزاً للعمل.
2. **إضافة كابتن يدوياً وتحديد مساره:** يمكن للإدارة إضافة سائق مباشرة وتحديد خط سيره على الخريطة وتوليد كلمة مرور فريدة له ومشاركتها معه عبر الواتساب.
3. **المراقبة والإحصائيات:** مؤشرات حية لعدد الرحلات، الإيرادات، الكباتن النشطين، والشكاوى الجارية.

## 🗺️ المحرك الجغرافي والخرائط (Spatial Engine & Mapbox)

- **مزود الخرائط الأساسي:** Mapbox GL JS v3.2.0 & Mapbox Directions / Geocoding APIs.
- **تتبع الشوارع الحقيقي (Road-Snapping):** لا ترسم المسارات كخطوط مستقيمة تقليدية، بل ترسل إحداثيات البداية والنهاية ومحطات التوقف إلى Mapbox Directions API لاسترجاع مسار الشوارع الفعلي (`driving` profile) بدقة متناهية.
- **دعم اللغة العربية والـ RTL:** تفعيل مكون `mapbox-gl-rtl-text` لضمان ظهور أسماء شوارع وأحياء النجف والأرقام العربية باتجاه صحيح وواضح.

## ☁️ البيئة السحابية وإعدادات السيرفر (Production Infrastructure & Nginx)

- **عنوان الخادم (VPS):** `173.212.206.86` (Ubuntu Linux 24.04).
- **الخدمة المدارة (PM2):** اسم التطبيق `taxi-wisam-api`، يعمل على المنفذ المحلي `5050`.

## 📡 واجهات برمجة التطبيقات (API Reference)

| الرابط (Endpoint) | الطريقة (Method) | الوصف |
|---|---|---|
| `/api/admin/stats` | `GET` | إحصائيات لوحة التحكم اللحظية (سائقين، مسارات، رحلات، وثائق) |
| `/api/admin/drivers` | `GET` | جلب قائمة كافة السائقين المسجلين وحالاتهم |
| `/api/admin/drivers/pending-verifications` | `GET` | قائمة طلبات التوثيق المعلقة لفحص الوثائق الأربعة |
| `/api/admin/drivers/:id/verify-doc` | `POST` | اعتماد أو رفض وثيقة معينة للسائق مع ذكر السبب |
| `/api/admin/drivers/create` | `POST` | إضافة كابتن جديد من لوحة التحكم مع مساره على الخريطة |
| `/api/admin/customers` | `GET` | جلب قائمة الركاب المسجلين |
| `/api/admin/customers/:id/update` | `POST` | تحديث بيانات الراكب وتغيير كلمة مروره |
| `/api/admin/settings` | `GET / POST` | جلب وتحديث معايير محرك المطابقة والتسعير |
| `/api/auth/register-passenger` | `POST` | تسجيل حساب راكب جديد وحفظ بياناته في قاعدة البيانات |
| `/api/auth/login-passenger` | `POST` | تسجيل دخول الراكب والتحقق من كلمة المرور |

## 🤖 إرشادات المطورين ونماذج الذكاء الاصطناعي (Guidelines for Developers & AI Agents)

إذا كنت مبرمجاً جديداً أو نموذج ذكاء اصطناعي تتولى تطوير هذه المنصة، يرجى الالتزام التام بالقواعد التالية:

1. **سلامة الإعدادات الحالية:** لا تقم بإعادة ضبط أو مسح جداول أو إعدادات التسعير والمسافات الموجودة في `state.json` أو قاعدة البيانات.
2. **فصل مسارات الـ Nginx:** عند إضافة أي أصول برمجية جديدة تحت `/dashboard/`، تأكد دائماً أن مسار Nginx يحتوي على `^~` (`location ^~ /dashboard`) لمنع اعتراض ملفات الـ JS والـ CSS بواسطة قواعد الملفات الثابتة.
3. **حماية التوكنات والبيانات الحساسة:** لا تقم برفع مفاتيح Mapbox أو Google Secrets الصريحة في سطور منفردة داخل الكود لتجنب حظر الرفع بواسطة GitHub Push Protection، واستخدم دائماً متغيرات البيئة (`process.env`) أو التجزئة الآمنة.
4. **دعم اللغة العربية والواجهات:** كل رسائل النظام وأسماء المدن والشوارع يجب أن تحافظ على الصياغة العربية السليمة المتوافقة مع أسلوب وثقافة أهل العراق والنجف الأشرف.
