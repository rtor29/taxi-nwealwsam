التكسي الفوري فقط

القيم الأساسية لاحتساب كروة المشوار المباشر بالدينار العراقي (لا تؤثر على خطوط الاشتراكات الثابتة).

تقريب الكاش التصاعدي الصارم: يتم تدوير كل الكراوي تصاعدياً لأقرب 250 دينار عراقي (Math.ceil) مثل 3,000 أو 3,250 أو 3,500 د.ع لحماية حق الكابتن والراكب وتفادي الفكة.
